## 问题

单 Agent 顺序处理多个独立分析会增加总时长，也容易把不同角色的证据混在一起。

## 解决方案

为 2–4 名成员提供共同目标和不重叠任务，并用 allSettled 保留部分成功证据。

## 工作原理

1. 验证成员数量、身份与任务边界。
2. 并行启动隔离 Agent。
3. 禁止嵌套团队。
4. 汇总每名成员的完成或失败状态。

### 执行链

```text
objective → specialist tasks ⇉ isolated agents → settled evidence → synthesis
```

模型负责决定下一步，Harness 负责校验、执行、记录和限制。失败也作为观察返回模型，而不是被隐藏。

让一名成员失败，确认其他成员结果仍返回；再检查重复任务是否真的带来新证据。

建议同时记录：模型看见了什么 Schema、Harness
实际执行了什么、结果如何回到消息历史，以及取消或失败发生在哪一层。
