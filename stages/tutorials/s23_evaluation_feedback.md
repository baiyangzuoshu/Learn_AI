# s23：Tool Contracts and Permission

## 合并范围

整合工具注册、权限模式、安全治理、DLP、IAM 和 Red-team 的执行边界。

## 学习重点

每个工具都有单一责任、输入契约、mutation
分类、scope、过期身份和输出上限。模型只能请求工具，不能批准自己的权限。

## 练习

1. 区分只读、变更、外部副作用和危险工具。
2. 为高风险工具增加人工审批和审计事件。
3. 给越权、超大输出和格式错误写负例。

## 生产迁移

将策略放入生产 Permission 系统，统一执行路径，避免 Tool Handler 各自判断安全。
