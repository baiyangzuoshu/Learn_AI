# s17：有界自治循环

源码：[s17_autonomous_agent.ts](../s17_autonomous_agent.ts)

## 学习目标

- 理解观察、行动、验证的迭代过程。
- 为自治任务定义成功标准和最大次数。
- 识别模型自我声明成功的风险。

## 核心机制

`autonomous_run` 在严格迭代上限内反复调用
Agent，每轮携带目标、成功标准和之前证据。模型输出完成标记后提前停止，否则返回迭代耗尽。

## 运行与观察

```sh
deno task s17
```

选择一个可验证的小任务，比较模型声称完成与实际检查结果。

## 练习

用独立 Verifier 替代字符串完成标记，并检测连续重复动作。
