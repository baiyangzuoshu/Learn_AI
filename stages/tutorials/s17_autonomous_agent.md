# s17：有界自治循环

源码：[s17_autonomous_agent.ts](../s17_autonomous_agent.ts)

## 学习目标

- 理解观察、行动、验证的迭代过程。
- 为自治任务定义成功标准和最大次数。
- 识别模型自我声明成功的风险。

## 核心机制

`autonomous_run` 在严格迭代上限内反复调用
Agent，每轮携带目标、成功标准和之前证据。模型输出完成标记后提前停止，否则返回迭代耗尽。

## 自治的本质是有界反馈循环

自治并不是“让模型一直跑”。每轮都应观察当前状态、选择行动、验证结果，再决定继续、完成或转向。启动前必须定义目标、可判定成功标准和资源上限。

`autonomous_run`
把上一轮证据带进下一轮，并设置严格迭代数。完成标记可提前退出，耗尽时明确返回未完成，而不是伪装成功。这比无限
`while` 安全，但字符串标记仍是模型自我声明，不能证明文件、测试或外部状态真的符合要求。

生产 Verifier
应从环境独立取证，例如运行测试、读取目标状态或使用确定性断言。连续重复相同动作意味着停滞，应停止、重新规划或请求帮助。每轮还要共享总时间、工具和成本预算，并传播取消。

自治只扩大持续行动能力，不扩大权限。每个工具仍经过 s03 的授权边界。

## 运行与观察

```sh
deno task s17
```

选择一个可验证的小任务，比较模型声称完成与实际检查结果。
