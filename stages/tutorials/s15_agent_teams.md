# s15：Agent Teams

源码：[s15_agent_teams.ts](../s15_agent_teams.ts)

## 学习目标

- 将大任务拆成多个不重叠的专家任务。
- 掌握 2–4 个成员的并行执行与结果汇总。
- 理解部分失败为什么不能丢弃其他成员结果。

## 核心机制

`team_run` 使用 `Promise.allSettled`
并行运行成员。每名成员获得角色、子任务和共同目标，最终结果保留成功与失败状态。嵌套团队被禁止。

## 运行与观察

```sh
deno task s15
```

让两个专家分别分析安全和架构，观察并行结果以及一个成员失败时的汇总行为。

## 练习

为团队增加总 Token 预算和成员工具白名单。
