# s09：项目长期记忆

源码：[s09_memory.ts](../s09_memory.ts)

## 学习目标

- 区分对话历史和跨会话项目记忆。
- 掌握按工作区隔离的读取、追加和替换。
- 理解记忆中不能保存密钥和短期噪声。

## 核心机制

`memory_read` 加载项目记忆，`memory_append` 追加稳定事实，`memory_replace`
用精简版本整体替换。记忆以工作区摘要作为文件标识，并通过事件显示加载或更新状态。

## 运行与观察

```sh
deno task s09
```

保存一条稳定架构约束，重新运行后读取它；不要保存 API Key 或一次性任务状态。

## 练习

加入记忆去重、过期日期和冲突检测。
