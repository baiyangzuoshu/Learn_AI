# s07：按需加载 Skill

源码：[s07_skill_loading.ts](../s07_skill_loading.ts)

## 学习目标

- 理解 Skill 是可复用的任务说明，而不是可执行工具。
- 掌握 Skill 发现与 `SKILL.md` 按需加载。
- 避免把所有 Skill 内容永久放入上下文。

## 核心机制

`list_skills` 只返回可用名称，`load_skill` 才读取选中的
`SKILL.md`。这种渐进加载减少上下文占用，也让模型根据任务选择适用流程。

## Skill 与 Tool 的边界

Tool 是可以执行的动作；Skill 是完成某类任务时应遵循的知识和流程。Skill
不直接产生副作用，而是改变模型如何组合已有工具。

若启动时载入全部 `SKILL.md`，成本会随数量增长，无关规则也会互相干扰。渐进披露先用 `list_skills`
暴露短目录，模型判断相关性后再用 `load_skill` 获取全文。

`roots()` 定义候选目录，`skillFiles()` 只接受安全名称并寻找
`SKILL.md`。加载时再次验证名称、解析已发现路径并限制正文长度。名称正则也是路径安全边界，避免用 `../`
把 Skill Loader 变成任意文件读取器。生产实现还需处理同名优先级、符号链接、版本与来源信任。

```text
发现名称 → 判断适用性 → 加载一个 Skill → 按流程调用现有工具
```

好的 Skill 应写清触发条件、步骤、验证方式和安全边界，而不是堆积常识。

## 运行与观察

```sh
deno task s07
```

在工作区创建一个测试 Skill，先列出再加载，确认非法名称和不存在的 Skill 会被拒绝。

## 练习

创建 `skills/review/SKILL.md`，验证 Agent
先发现再加载。随后增加版本、触发条件和依赖元数据，并设计同名 Skill 冲突时的确定性优先级。
