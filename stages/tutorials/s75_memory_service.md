# s75：生产 Memory Service

## 本课目标

把记忆从 Prompt 附件提升为独立服务：按租户和类型保存，使用词法与向量信号混合检索，并处理过期数据。

## 核心机制

- `MemoryBackend` 使文件、数据库和向量库可替换。
- `embed` 与 cosine 演示语义信号，词法信号补充精确匹配。
- 召回前检查租户和 TTL，避免跨租户或过期事实进入上下文。

## 练习

1. 加入语义/情景/程序三类 retention 和 tombstone。
2. 使用真实 ANN、图索引和 hybrid rerank。
3. 记录召回命中率、引用覆盖率和记忆删除传播。

## 生产边界

课程 Embedding 是确定性占位实现；生产需要真实向量库、加密、迁移、备份和数据保留策略。
