PREFERENCES

设置

配置 Claude Code CLI 使用的 Anthropic 兼容接口。密钥以明文本地文件保存，仅当前用户可读写，不使用钥匙串。

本机文件存储
新密钥以明文保存在本机权限受限文件中，不写入项目仓库或钥匙串。
CLI 状态检查中

权限确认

启用完全放开？

Claude Code 将跳过工具权限确认，可以运行任意本地命令并访问当前用户可读写的文件，包括所选项目目录以外的文件。命令也可能通过网络发送数据。请只在你信任的项目中使用。

删除会话？

此会话的消息与聊天记录将被永久删除。

项目文件及同项目的其他会话会保留

移除项目？

此项目下的会话和聊天记录将从 Studio 中移除。

项目文件与代码将保留在原位置
