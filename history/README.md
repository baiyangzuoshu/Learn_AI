# AI 发展史（2022—2026）

这里记录 2022—2026 年人工智能发展的全过程，关注四条互相交织的线索：

1. **事件**：模型发布、产品上线、公司与产业变化、政策与社会事件。
2. **技术**：训练方法、模型架构、模态扩展、推理、Agent 与具身智能。
3. **数据**：模型规模、训练数据、成本、用户、融资、基准表现等可核查指标。
4. **影响**：对开发者、创作者、企业、科研和治理的实际影响。

## 阅读方式

- `timeline/`：按年份的主时间线。
- `technology/`：按年份解释模型结构、训练方法、数据、评测和系统工程。
- `biographies/`：以《史记》本纪、世家、列传体例记录重要模型、公司与产品的独立发展史。
- `data/`：结构化数据和可用于制图的表格。
- `sources/`：来源索引和资料说明。

每条重要记录尽量包含：日期、参与者、发生了什么、为什么重要、可核查数据、原始来源，以及“事实”和“解释/判断”的区分。

## 校验

可运行 `python3 history/scripts/validate_yearbooks.py` 检查年度文件、CSV 字段、HTTPS 来源、事实矩阵与数据快照逐条映射、2026 截止日期和传记覆盖情况。

## 资料原则

- 优先使用论文、官方研究博客、产品公告、监管机构文件和统计报告。
- 二手报道只用于补充背景，不作为关键数字的唯一依据。
- 可能随版本变化的数据注明统计日期；模型能力比较注明基准、版本和测试条件。
- 对尚无共识的判断标记为“分析”，不写成确定事实。
