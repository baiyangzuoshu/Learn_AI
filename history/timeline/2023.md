# 2023：从聊天产品到 AI 平台

> **年度判断（分析）**：2022 年证明大众愿意使用生成式 AI；2023 年则把它推进到模型竞赛、多模态、开源生态、工具调用、企业服务和政府治理。技术焦点从“能不能生成”转向“能不能更可靠地完成任务”。

前史：[2022 年之前 AI 的发展](2022年之前AI的发展.md)；上一年度：[2022：生成式 AI 的引爆年](2022.md)。技术细节见：[2023 技术深度](../technology/2023.md)。

## 二、2023 年的五条主线

### 1. GPT-4 把模型竞争推向可靠性和复杂任务

GPT-4 的意义不只是参数更大，而是模型在专业考试、代码、复杂指令和安全对齐方面更接近可用产品。OpenAI 同时强调，GPT-4 仍会产生幻觉，且完整架构、训练数据规模和计算量并未公开。

### 2. 多模态成为基础模型的下一站

图像理解、语音、视频和文本生成开始进入同一产品界面。GPT-4V、Gemini、PaLM 2、SAM、DALL·E 3 等路线分别从视觉输入、原生多模态、视觉基础模型和可控生成推进边界。

### 3. 开源模型生态爆发

LLaMA 公开研究模型之后，Alpaca、Vicuna、OpenAssistant、Llama 2、Code Llama、Falcon、Mistral 等模型和微调项目迅速出现。模型能力不再只由少数公司通过 API 提供，开发者开始在本地部署、量化、微调和构建专用模型。

### 4. 模型开始使用工具

插件、函数调用、检索、代码解释器和 Assistants API 使模型可以把自然语言转换成结构化动作。AI Agent 的核心不只是“模型更聪明”，还包括记忆、规划、工具权限、执行反馈和错误恢复。

### 5. 治理进入产品周期

生成式 AI 监管从原则讨论进入实际规则：数据来源、个人信息、版权、深度伪造、模型评估、红队测试和服务提供者责任成为发布流程的一部分。

## 四、这一年留下的问题

- 多模态模型是真的统一建模，还是多个专用模块的组合？
- 开源模型的“开放”包括权重、数据、代码、许可证和训练过程中的哪些部分？
- 函数调用和 Agent 如何防止提示注入、越权操作和错误执行？
- 生成内容的版权、来源标记和责任边界如何落地？
- benchmark 分数提升是否等于真实工作质量提升？
