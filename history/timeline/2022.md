# 2022：生成式 AI 的引爆年

> **年度判断（分析）**：2022 年的关键变化不是某一个模型突然出现，而是几条技术路线在同一年完成了从研究成果到可见产品的跃迁：大语言模型的规模化与数据配比被重新认识，文本到图像模型开始面向大众，视觉—语言模型扩展了模态边界，RLHF 与 Constitutional AI 推动了对齐方法的发展，ChatGPT 则把这些成果变成了普通人可以直接使用的对话产品。

阅读前史：[2022 年之前 AI 的发展](2022年之前AI的发展.md)。

## 一、年度时间线

| 日期 | 事件 | 技术/产业意义 |
|---|---|---|
| 2022-01 | OpenAI 的 InstructGPT 研究公开发表 | 以人类示范和偏好反馈训练模型遵循指令，为后来 ChatGPT 的产品形态和 RLHF 路线奠定基础。 |
| 2022-02（论文于 2022-12 正式发表） | DeepMind 发布 AlphaCode 研究 | 代码生成模型在竞赛编程任务上取得接近人类参赛者的表现，使“AI 编程”从自动补全进一步进入算法问题求解。 |
| 2022-04-04 | Google 发布 PaLM 研究 | PaLM 以 5400 亿参数展示了大规模语言模型在推理、代码和多任务上的能力，强化了“基础模型 + 规模化训练”的路线。 |
| 2022-04-12 | DeepMind 发布 Chinchilla 研究 | 研究指出许多模型“参数过大、训练数据不足”；70B 参数、1.3T tokens 的 Chinchilla 在相同训练计算预算下超过更大的 Gopher，改变了后续模型的训练配比。 |
| 2022-04 | OpenAI 开始 DALL·E 2 研究预览 | 文本到图像生成从研究演示走向真实用户测试；后续的安全过滤、分阶段开放和内容政策也成为生成式产品的早期范式。 |
| 2022-04-28 | DeepMind 介绍 Flamingo | 80B 参数视觉语言模型把图像、视频和文本纳入统一的少样本学习框架，推动多模态基础模型成为独立方向。 |
| 2022-05 | Google 公开 Imagen 研究 | 文本到图像生成在大语言模型文本编码器和扩散模型结合的方向上继续推进，提升了语言理解与图像质量。 |
| 2022-07 | BLOOM 开源发布 | 多国研究者合作的大型多语种模型向公众开放，体现了开放模型、跨语言和研究可复现性的另一条路线。 |
| 2022-08-22 | Stable Diffusion 公开发布 | 高质量文本到图像模型可下载、可本地运行并被社区二次开发；生成式图像生态从少数公司控制的 API 迅速扩散到开源社区。 |
| 2022-09-28 | DALL·E 取消 waitlist | OpenAI 表示 DALL·E 已有超过 150 万活跃用户、每天生成超过 200 万张图像，文本到图像成为大规模消费产品。 |
| 2022-11-15 | Meta 发布 Galactica，随后暂停公开演示 | 事件暴露出“面向科学写作的生成模型”在事实错误、来源幻觉和产品定位上的风险，成为生成式 AI 可靠性讨论的早期案例。 |
| 2022-11-30 | OpenAI 发布 ChatGPT 研究预览 | 对话式交互把大语言模型的问答、写作、代码和连续追问能力带给大众，生成式 AI 进入公众产品与社会讨论中心。 |
| 2022-12-15 | Anthropic 发布 Constitutional AI 研究 | 提出用一组明确原则指导自我批评、修订和 RLAIF 训练，减少对人工有害样本标注的依赖，推动对齐方法从 RLHF 扩展。 |

## 二、五条技术主线

更详细的模型结构、训练流程、扩散模型、多模态、代码模型和评测分析见：[2022 技术深度章节](../technology/2022.md)。

### 1. 从“更大”转向“算力最优”

2022 年初的主流直觉仍偏向继续增加参数量。Chinchilla 研究给出重要修正：在固定训练计算预算下，模型参数和训练 token 需要更均衡地增长。这个结论影响了后续模型的训练配方、推理成本和部署策略。

### 2. 文本生成与图像生成同时产品化

DALL·E 2、Imagen、Midjourney 和 Stable Diffusion 让“用自然语言描述并生成图像”成为大众可感知的能力。闭源服务和开源权重并行出现，带来了速度、成本、版权、内容安全和创作者权益等新问题。

### 3. 多模态从拼接工具走向基础模型方向

Flamingo 等研究把视觉、视频与语言放进统一的少样本学习框架。虽然当时距离今天的实时多模态助手仍很远，但“一个模型处理多种输入和输出”已成为明确的研究路线。

### 4. 对齐从实验方法变成产品基础设施

InstructGPT 代表的人类反馈训练与 Anthropic 的 Constitutional AI 代表的 AI 反馈/原则约束，分别探索了“如何让模型更有用”和“如何让模型更安全”。ChatGPT 的公开预览也体现了通过真实用户反馈进行迭代部署的思路。

### 5. 生成式模型进入代码与科学场景

AlphaCode、GitHub Copilot 的早期普及、Galactica 的尝试说明：模型不再只生成一般文本或图片，也开始进入编程、科学写作和知识工作。但 Galactica 事件同时提醒人们，流畅表达不能等同于事实可靠。

## 三、2022 年可核查的数据快照

| 指标 | 数值/状态 | 来源与说明 |

| Chinchilla 训练数据 | 1.3T tokens | DeepMind，2022-04-12。 |
| DALL·E 2 研究预览阶段累计生成图像 | 超过 3M | OpenAI，2022-05-18。 |

这些数字不能直接组成“模型能力排行榜”：它们的统计口径、时间点和产品阶段不同，后续制图时应保留来源、版本和测量条件。

## 四、这一年留下的问题

- 生成内容的事实性、可解释性和来源追踪如何保证？
- 训练数据中的版权、个人信息和偏见应如何处理？
- 开源权重降低了创新门槛，也降低了滥用门槛，开放边界如何设计？
- 模型规模增长的成本由谁承担，算力和数据是否会进一步集中？
- 对齐究竟应由人工偏好、明确原则、法律法规还是多方治理共同决定？
