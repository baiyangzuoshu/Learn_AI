# 2025：推理模型、Agent 与开放权重重新洗牌

## 一、年度总述

如果说 2024 年是模型获得“感官”和“工具”，那么 2025 年是模型开始被当作“执行系统”来部署：它们在回答前投入更多推理计算，能够浏览网页、操作电脑、运行代码、生成报告和维护长流程任务；与此同时，DeepSeek-R1、Qwen3、Llama 4 与 OpenAI gpt-oss 让开放权重重新成为前沿竞争的中心。

2025 年的竞争不再只有“谁的聊天模型分数最高”，而是同时比较四件事：推理质量、工具调用、任务完成率和单位成本。闭源实验室以 GPT-5、Claude 4、Gemini 2.5 等统一系统推进，开放模型则以强化学习、MoE、蒸馏和本地部署扩大影响。欧盟《人工智能法案》对通用人工智能模型的义务在 8 月 2 日开始适用，模型治理正式进入产品生命周期。

## 二、年度时间线

### 1 月：DeepSeek-R1 与浏览器 Agent

- **1 月 20 日**：DeepSeek 发布 DeepSeek-R1，采用大规模强化学习、冷启动数据和蒸馏路线，公开模型、技术报告及多个小模型版本。推理能力从闭源实验室的产品优势，变成开放社区可以复现、蒸馏和部署的工程路线。
- **1 月 23 日**：OpenAI 发布 Operator 研究预览。Operator 使用自己的浏览器，通过截图、点击、输入和滚动完成网页任务，Computer-Using Agent（CUA）把 2024 年的 Computer Use 推向真实网页环境。
- **1 月**：推理模型、浏览器操作和本地部署成为开发者讨论的三条主线，2025 年被广泛视为 Agent 产品化的关键年份。

### 2 月：混合推理进入普通模型

- **2 月 24 日**：Anthropic 发布 Claude 3.7 Sonnet 与 Claude Code。Claude 3.7 可以在快速回答和 extended thinking 之间切换，Claude Code 则把终端、代码库和长任务交给模型协作完成。
- **2 月**：推理不再只对应一个单独的“思考模型”，而开始成为同一模型的可调预算：简单任务快速回答，复杂任务投入更多测试时计算。

### 3 月：Gemini 2.5 与通用 Agent 预热

- **3 月**：Google 推出 Gemini 2.5 系列，强调 thinking、长上下文、多模态和下一代 Agent 能力。模型路由、推理预算和工具使用被放进同一产品架构。
- **3 月 6 日**：Manus 公开发布，通用 Agent 以浏览器、代码执行、文件处理和任务交付为核心，推动公众重新讨论“AI 能否替人完成工作”。
- **3 月**：Google DeepMind 继续推进 AI for Science、机器人和通用世界理解，模型的评价对象从文本答案扩展到环境交互和科学发现。

### 4 月：开放模型与编码 Agent 集中爆发

- **4 月 16 日**：OpenAI 发布 o3 与 o4-mini。模型能够在 ChatGPT 中使用搜索、代码、图像生成等工具，并把视觉输入纳入推理过程；推理模型从“更会想”走向“会调用工具解决问题”。
- **4 月**：OpenAI 发布 GPT-4.1 系列和 Codex CLI，代码模型开始直接进入终端和软件工程工作流。
- **4 月 5 日前后**：Meta 发布 Llama 4 系列，主打原生多模态、MoE、长上下文和 Meta AI 产品整合，开放模型继续与闭源前沿模型正面竞争。
- **4 月 29 日**：阿里巴巴发布 Qwen3，包含 0.6B—235B 多种尺寸、Dense 与 MoE 模型，首次把“思考模式/非思考模式”结合到同一开放模型家族，并原生支持工具调用与 MCP。

### 5 月：Claude 4、Veo 3 与视频生成产品化

- **5 月 20 日**：Google 发布 Veo 3、Imagen 4 和 Flow。Veo 3 可生成带环境声、对白和音效的视频，Flow 将模型组合成面向创作者的 AI 电影工作流。
- **5 月 22 日**：Anthropic 发布 Claude Opus 4 与 Claude Sonnet 4，强调代码、长程推理和 AI Agent。Claude Code 从研究预览进一步成为软件工程产品入口。
- **5 月**：模型厂商开始把“生成—执行—验证—修复”作为代码 Agent 的基本循环，SWE-bench、Terminal-Bench、浏览器任务和真实软件项目成为新的评测场景。

### 6 月：Agent 平台和推理服务继续扩张

- **6 月 10 日**：OpenAI 推出 o3-pro，面向需要更长思考时间和更高可靠性的复杂任务。
- **6 月**：企业平台把 MCP、函数调用、知识库、浏览器和代码沙箱组合成可配置 Agent；模型供应商的差异越来越体现在工具生态、权限管理和可观测性。
- **6 月**：视频、语音和实时交互产品继续降低创作门槛，但版权、肖像、声音同意和内容溯源问题同步扩大。

### 7 月：Grok 4 与“模型自选搜索”

- **7 月 9 日**：xAI 发布 Grok 4 与 Grok 4 Heavy，强调强化学习规模化、原生工具使用和实时搜索。模型可以自行生成搜索查询，并从 X 与互联网信息中继续研究。
- **7 月 17 日**：OpenAI 发布 ChatGPT agent，将 Deep Research、Operator 的浏览器操作和 ChatGPT 的对话能力合并。Agent 可以浏览网页、运行代码、读取连接器数据并生成演示文稿和表格。
- **7 月**：Agent 的产品定义从“自动对话”转为“在受控环境中完成可交付任务”，用户确认、登录接管、权限边界和操作回放成为必备机制。

### 8 月：GPT-5、gpt-oss 与欧盟 GPAI 义务

- **8 月 2 日**：欧盟 AI Act 关于通用人工智能模型（GPAI）的义务开始适用，涉及技术文档、版权政策、训练内容摘要和系统性风险模型的额外责任。
- **8 月 5 日**：OpenAI 发布 gpt-oss-120b 与 gpt-oss-20b，采用 Apache 2.0 的开放权重推理模型，支持本地部署和 Agent 工具调用。OpenAI 自 GPT-2 以来再次公开可下载的大模型权重，开放模型竞争被重新点燃。
- **8 月 7 日**：OpenAI 发布 GPT-5，将快速模型、推理模型、工具和路由器统一到 ChatGPT 与 API。模型产品从“多个型号供用户选择”转向“系统自动决定何时快速回答、何时深入思考”。

### 9—10 月：长程编码 Agent 进入下一阶段

- **9 月 29 日**：Anthropic 发布 Claude Sonnet 4.5，强化代码、计算机操作和长时间 Agent 任务，并为 Claude Code 增加检查点、上下文编辑、记忆工具和 VS Code 集成。
- **9—10 月**：开放模型和云平台继续推出代码、视觉、语音与 Agent 专用版本，模型能力从通用聊天进一步分化为编码、研究、客服、营销和端侧设备。
- **10 月**：企业开始把 Agent 评测从单轮 benchmark 转向长程任务成功率、成本、恢复能力、权限错误和人工接管率。
- **秋季**：视频模型、实时语音、AI 眼镜和机器人演示相互汇合，AI 开始成为“感知—决策—行动”系统，而不只是文本生成服务。

### 11—12 月：消费级 Agent 与开放生态延伸

- **11 月 17 日**：阿里千问应用开启公测，Qwen3 被用于深度研究、编码、相机和生活服务等任务；模型生态开始向“能办事的个人助手”迁移。
- **11 月 18 日**：Google 发布 Gemini 3，并将其接入 Gemini 应用、AI Mode、AI Studio、Vertex AI 和新的 Agent 开发平台 Antigravity。
- **年末**：各家继续推出更强的编码 Agent、研究 Agent、浏览器 Agent 和多模态模型，行业进入“模型 + 工具 + 工作空间 + 权限”的系统竞争。
- **2025 年底判断**：Agent 已经从实验演示进入产品，但多数系统仍需要人工确认、沙箱、权限约束和结果复核；“能行动”不等于“能负责”。

## 三、2025 年的七条主线

### 1. 推理时计算成为主战场

DeepSeek-R1、Claude 3.7、Gemini 2.5、o3/o4-mini 和 GPT-5 都把更多计算预算放到回答时。模型规模仍重要，但搜索、验证、反思和工具调用让“每个任务投入多少计算”成为新的产品旋钮。

### 2. Agent 从工具调用走向工作空间

Operator、Claude Code、ChatGPT agent、Manus 和各种编码 Agent 把浏览器、终端、文件、知识库和办公软件放进同一循环。Agent 的最小单位不再是一次函数调用，而是一个可暂停、可恢复、可审计的任务。

### 3. 开放权重重新成为前沿力量

DeepSeek-R1、Qwen3、Llama 4 和 gpt-oss 说明开放模型可以同时追求推理能力、低成本、端侧部署和开发者生态。开放权重并不等于开放数据、训练代码和治理责任，比较时必须分开记录。

### 4. 多模态生成进入创作流程

Veo 3、Flow、Imagen 4、语音和实时视觉工具让文本、图像、视频、音频逐步进入同一创作链。模型评价开始关注角色一致性、镜头连续性、口型与声音同步、版权和内容溯源。

### 5. 编码成为 Agent 的第一生产力场景

Claude Code、Codex CLI、Cursor、Devin、Qwen3-Coder 等产品把代码库理解、终端执行、测试和修复连接起来。软件工程成为最适合验证 Agent 的领域，因为结果可以通过编译、测试和版本控制检查。

### 6. 监管开始约束基础模型提供者

欧盟 GPAI 义务在 2025 年 8 月 2 日适用，训练数据摘要、版权政策、技术文档和系统性风险治理成为模型发布的一部分。监管不再只针对最终应用，也开始直接触及基础模型供应商。

### 7. 数据和成本决定规模化

模型调用价格继续下降，但 Agent 任务会产生更多上下文、工具调用和失败重试。真正的单位经济性不能只看单次 token 价格，还要计算任务成功率、人工接管、工具成本、延迟和错误恢复成本。

## 四、年度判断

2025 年不是 Agent 已经成熟的一年，而是 Agent 的评价标准发生变化的一年。模型从“回答得像人”转向“在边界内完成任务”，推理从隐藏能力转为可调预算，开放模型从追赶者转为生态竞争者。2026 年真正需要回答的问题，是这些系统能否在更长时间、更高权限和更复杂组织流程中保持可靠。
