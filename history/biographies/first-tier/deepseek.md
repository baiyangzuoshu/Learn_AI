# DeepSeek 本纪

> **体例说明**：DeepSeek 既是模型家族，也是围绕高效训练、开源权重、代码和推理形成的研究与产品体系。本篇会区分 DeepSeek 的研究模型、API 产品和公开模型权重。

## 史家总评

DeepSeek 的历史意义，在于它把“前沿能力必须依赖极高训练成本”的命题变成了可检验的问题。它以 MoE、注意力压缩、数据效率、工程优化和开放发布，逐步形成“较低成本获得高能力”的路线；V3 与 R1 又把这种路线推向全球模型竞争中心。

## 一、身世与前史

DeepSeek 与 High-Flyer 量化投资技术背景相关，早期重点集中在大规模训练、代码和中文英文双语能力。2023—2024 年的 DeepSeek LLM、DeepSeek Coder 和 V2 系列，逐渐形成基础模型、代码模型、聊天模型和 API 产品线。

早期 DeepSeek 的重要选择，是公开模型权重、技术报告和推理代码，让研究者可以检查模型结构、部署方法和训练经验。

## 二、2024 年：效率路线成形

### 1. DeepSeek-V2

2024 年 5 月发布的 DeepSeek-V2 是一个 Mixture-of-Experts（MoE）模型：总参数量约 236B，但每个 token 激活约 21B 参数。模型同时采用 Multi-head Latent Attention（MLA），减少 KV cache，从而降低推理成本并提高吞吐。

DeepSeek-V2 的技术命题是：模型总容量可以很大，但每一步不必激活全部参数；注意力缓存也可以被压缩，长上下文服务不必线性承担全部显存成本。

### 2. V2.5 与代码能力

V2.5 将通用模型和代码模型能力合并，强化指令遵循、写作、代码和中文任务。DeepSeek 的模型家族不再只追求一个综合分数，而是把代码、数学、推理和通用对话统一到可部署的 API 体系中。

### 3. DeepSeek-V3

2024 年 12 月发布的 DeepSeek-V3 采用 671B 总参数、每 token 激活约 37B 的 MoE 架构，在 14.8T tokens 上预训练，并继续使用 MLA、DeepSeekMoE、辅助损失自由的负载均衡和多 token 预测等方法。

V3 的影响不只是 benchmark：它公开了大规模训练稳定性、GPU 小时、架构选择和工程优化，使行业开始更认真地比较“能力 / 激活参数 / 训练成本 / 推理成本”。

## 三、2025 年：R1 与推理模型

### 1. R1-Zero：让强化学习产生推理行为

2025 年 1 月，DeepSeek 发布 R1 系列。R1-Zero 的重要实验是：在没有先进行传统监督微调的情况下，直接通过大规模强化学习探索推理能力。模型在数学、代码和逻辑任务中逐渐形成更长的思考、验证和自我检查行为，但可读性和语言稳定性存在问题。

### 2. R1：冷启动数据与强化学习结合

正式的 R1 加入多阶段训练和冷启动数据，改善了可读性、语言一致性和推理表现，并开放 R1 及多个蒸馏模型。蒸馏路线把大模型推理行为迁移到更小的 Qwen/Llama 基础模型，扩大了推理模型的可部署范围。

### 3. 推理模型的历史位置

R1 让“后训练强化学习是否能显著提高通用推理”成为全球共同问题。它把竞争焦点从预训练参数量扩展到：奖励设计、可验证任务、思考长度、推理时计算和蒸馏。

## 四、技术变法

- **MoE**：总参数很大，但每个 token 只激活少量专家，降低计算量。
- **MLA**：压缩注意力缓存，降低长上下文推理的内存压力。
- **高质量数据**：在有限算力下提高 token 质量和数据配比。
- **强化学习推理**：把数学、代码等可验证任务的结果作为奖励。
- **开放权重与蒸馏**：让研究者在本地复现和迁移能力。

## 五、争议与边界

DeepSeek 的开放策略和成本叙事推动了行业竞争，但模型比较仍需谨慎：训练成本口径、硬件租赁、工程投入、数据来源、API 价格和 benchmark 条件并不完全相同。开放权重也不等于开放全部训练数据、代码、过滤流程和治理责任。

## 七、当年位置

DeepSeek 的核心贡献不是简单地证明“某个中国模型也能达到高分”，而是把效率、开放、推理后训练和工程细节推到台前。它改变了行业提问方式：不再只问“谁的模型最大”，还要问“谁能以更少激活参数、更低成本和更开放的方式完成同一任务”。

### 2026 年（截至 8 月 15 日）

DeepSeek-V4 把 2025 年 R1 引发的开放推理路线继续向前推进。此时判断 DeepSeek 不能只看模型名称或参数规模，还要看开放权重、国产硬件适配、长上下文、多模态、Agent 能力和真实 API 成本能否同时成立。

## 八、史家曰

> DeepSeek 起于算力约束，成于工程精算，显名于推理之火。其长不在声势，而在把参数、缓存、专家、数据与奖励一一算清。后世论 DeepSeek，不当只看一时榜单，须观其是否令天下模型皆被迫回答同一问题：能力究竟由多少参数决定，又有多少来自训练方法与系统之巧。
