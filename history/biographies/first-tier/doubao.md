# 豆包本纪

> **体例说明**：豆包不是单一模型名，而是字节跳动面向用户的 AI 助手，以及背后的豆包大模型、火山方舟和 Seed 系列模型组成的产品—模型体系。

## 史家总评

豆包的历史价值，在于它把大模型竞争带入中文互联网的高频场景：对话、写作、学习、代码、图片、语音、视频和内容创作。它背靠字节跳动的内容分发、推荐、音视频和云服务能力，采取大规模免费入口与低成本 API 并行的路线。

## 一、身世：云雀、字节与火山方舟

豆包背后的技术前身通常与字节跳动的云雀大模型研发相联系。字节跳动将模型能力封装为用户可直接使用的豆包助手，并通过火山引擎向开发者和企业提供模型服务。

这种组织方式与单纯发布一个模型不同：模型研发、应用产品、内容生态、云平台和企业服务被放在同一条产业链中。

## 二、2023 年：面向公众的对话助手

2023 年，豆包作为 AI 对话助手面向公众开放，逐步提供对话、写作辅助、知识问答和代码生成等功能。它的早期竞争重点不是只在研究论文中争夺榜单，而是尽快进入普通用户的日常场景。

豆包的产品形态体现了中文用户对 AI 助手的现实需求：写小红书和短视频文案、改写公文、辅导学习、总结资料、生成图片、处理表格和协助代码。

## 三、2024 年：模型家族与火山方舟

2024 年 5 月，火山引擎正式对外发布豆包大模型家族并提供 API。模型从通用语言能力扩展到视觉理解、语音识别、语音合成、图像创作和视频生成等多个方向。

豆包的产业路线可以拆成三层：

1. **豆包 App**：面向个人用户的对话和创作入口；
2. **豆包大模型**：通用、视觉、语音、代码和生成模型家族；
3. **火山方舟**：模型调用、微调、评测、向量数据库和 Agent 的企业平台。

### 技术路线

- 中文语境和内容生产场景优化；
- 通用模型与专业模型并行；
- 多模态理解和生成；
- 低价格、高吞吐的 API 服务；
- 与抖音、剪映、飞书和企业内容流程结合。

2024 年，豆包的关键变化不是只增加一个更大的参数规模，而是把模型家族拆成通用、视觉、语音、图像和视频等服务，并通过火山方舟提供统一的模型调用、微调、评测和 Agent 接入。对普通用户而言，豆包仍是助手；对企业而言，它逐渐变成一套可嵌入内容生产与办公流程的模型平台。

## 四、2025 年：推理、视频与 Agent 平台

2025 年，豆包继续沿着“模型家族 + 火山方舟 + 字节内容生态”推进。它不再只是聊天入口，而是把推理、文本、语音、图像、视频、搜索和企业工作流组合成一组可调用的能力；在国内大模型竞争从“能否聊天”转向“能否交付任务”之后，豆包的重点也转向 Agent、内容创作和开发者平台。

## 五、2026 年（截至 8 月 15 日）：多模态 Agent 的持续整合

2026 年，豆包继续围绕中文用户入口、火山方舟和字节内容生态推进推理、视频、语音、搜索、代码与 Agent 工作流。由于模型与产品更新频繁，本纪暂以“能力组合、调用平台和落地场景”为主，不把未经稳定发布的内部型号写成确定事实。

## 六、功与过

### 功

- 将中文大模型快速带入大众用户和内容创作场景；
- 把模型能力与短视频、图片、语音、办公和教育需求连接；
- 通过火山方舟降低企业调用、微调和部署门槛；
- 推动中国大模型的价格竞争和应用普及。

### 过与边界

- 内容平台与生成式 AI 结合后，版权、低俗内容和虚假信息风险更集中；
- 中文场景表现不能自动代表所有专业领域都可靠；
- 免费和低价策略会扩大使用规模，也会增加安全、隐私和算力压力；
- 产品宣传中的 benchmark、用户量和“对齐”需要分别核验统计口径。

## 七、传记年表

| 时间 | 事件 | 本纪意义 |
|---|---|---|
| 2023 | 豆包 AI 助手面向公众开放 | 字节跳动以大众入口进入生成式 AI 竞争。 |
| 2023—2024 | 云雀与豆包模型体系扩展 | 从单一对话产品走向模型家族。 |
| 2024-05 | 豆包大模型家族和火山方舟对外服务 | 企业 API、微调、评测和多模态服务成形。 |
| 2024 下半年 | 视觉、语音、音乐、视频和 Agent 能力扩展 | 豆包从聊天助手走向内容与工作流平台。 |
| 2025 | 推理、多模态、视频与 Agent 平台继续扩展 | 从对话助手走向创作、搜索和企业工作流。 |
| 2026 | 截至 8 月 15 日 | 推理、多模态、视频、语音与 Agent 继续在内容和企业场景中整合。 |

## 八、当年位置

豆包的竞争力不应只用模型榜单衡量。它的核心资产是中文用户入口、内容生产场景、字节跳动的分发与音视频工程，以及火山方舟的企业服务。它代表一种中国式大模型路径：先把 AI 放进高频内容和日常工具，再以平台化方式向开发者开放。

## 九、史家曰

> 豆包生于内容之海，借云雀之翼，入百姓案头。其所长非独答问，乃能作文、作图、作声、作影，并随平台而入万业。然内容越盛，真伪与版权之责越重。后世论豆包，当观其能否以低门槛普惠众人，又能否在流量与信任之间守住边界。
