# Microsoft AI / Copilot 世家

## 史家总评

Microsoft AI 的历史不是一个孤立模型的历史，而是把基础模型嵌入搜索、浏览器、Windows、办公、代码、云和企业安全的“副驾驶”体系。它的核心竞争力是分发与工作数据，而非只拥有一个聊天窗口。

## 一、家世：Azure、Bing 与 OpenAI 合作

微软长期拥有搜索、Windows、Office、GitHub、Azure 和企业软件生态。与 OpenAI 的合作把 GPT 模型接入 Azure，并将生成式 AI 从实验室能力变成搜索、开发和办公产品。

## 二、2023 年：Bing Chat 到 Copilot

### 1. Bing Chat

2023 年 2 月 7 日，微软发布 AI 加持的 Bing 和 Edge，把搜索、网页浏览和聊天结合起来。它与 ChatGPT 的不同在于：搜索结果、网页内容和对话回答被放进同一流程，目标是让模型帮助用户查找并总结实时网页信息。

### 2. GitHub Copilot

代码副驾驶把自然语言、代码补全、编辑器和开发者工作流结合起来。它改变了 AI 编程的产品形态：模型不再单独回答代码问题，而是在用户编写代码的上下文中实时提出建议。

### 3. Microsoft Copilot 统一品牌

2023 年 9 月 21 日，微软宣布 Microsoft Copilot，将 Bing Chat、Windows、Edge、Microsoft 365 等 Copilot 体验统一到一个品牌之下；Windows Copilot 从 9 月 26 日开始逐步推出，Microsoft 365 Copilot 于 11 月 1 日面向企业正式可用。

## 三、2024 年：Copilot Pro 与企业工作流

2024 年 1 月 15 日，微软推出 Copilot Pro，面向个人用户提供更高等级模型访问、图像生成和在 Microsoft 365 个人版应用中的 Copilot 能力，并开放自定义 Copilot GPT 的方向。随后，Copilot 继续向 Windows、Edge、移动端、Microsoft 365、Security、Studio 和 Azure 扩展。

2024 年的产品重点不再只是“聊天窗口”，而是把模型放入邮件、文档、会议、代码和业务流程。企业 Copilot 的核心约束也更加清楚：模型只能使用用户有权限访问的 Graph 数据，权限、租户隔离、审计与人工复核决定了它能否真正进入生产环境。

## 四、技术变法

- **搜索 grounding**：把模型回答建立在网页检索和引用之上；
- **工作数据接入**：通过 Microsoft Graph 读取用户有权限访问的邮件、文档、会议和任务；
- **应用内嵌**：在 Word、PowerPoint、Excel、Outlook、Teams、Windows 和 Edge 中直接调用；
- **开发者副驾驶**：通过 GitHub、Azure OpenAI 和 Copilot Studio 形成代码与业务自动化生态；
- **企业安全**：把身份、权限、租户隔离、审计和数据保护纳入生成式 AI 产品。

## 五、2025 年：Copilot 从助手到 Agent 工作流

2025 年，Copilot 的重心从“在软件旁边回答问题”转向“在权限范围内完成工作”。Microsoft 继续把 Copilot Studio、GitHub Copilot、Security Copilot、Azure AI Foundry 和 Microsoft 365 工作流连接起来，企业 Agent 开始承担检索、分析、代码修改、审批准备和跨应用编排等任务。

## 六、功与边界

Microsoft Copilot 的优势是能够把模型放进已有软件和企业权限体系，减少用户切换工具的成本；难点在于企业数据权限极其复杂，模型即使能访问数据，也可能误解文档、混淆权限或生成不准确的摘要。

搜索型 Copilot 还面临引用质量、网页操纵、实时性和幻觉问题。企业 Copilot 则需要额外面对数据泄露、合规、日志、员工接受度和投资回报问题。

## 七、2026 年：从 Copilot 到组织级 Agent

2026 年，Copilot 的竞争重点进一步转向组织级 Agent：模型需要理解企业权限、跨应用数据、代码库和审批流程，并在必要时把任务交还人类。Microsoft 的优势仍在 Windows、Microsoft 365、GitHub、Azure 和 Security 的软件入口，但产品价值取决于治理层能否跟上自动化范围。

> **史家曰**：微软不造一城之 Chat，而造百业之 Copilot。其势在于把模型置于每一个软件入口，令 AI 不必召唤而随工作而来。然副驾驶虽近，方向盘仍在人手；权限、引用和责任，才是企业航行的真正风浪。
