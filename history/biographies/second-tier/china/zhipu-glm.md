# 智谱 GLM 世家

## 史家总评

智谱的道路，是从清华大学 GLM 研究、开源模型和代码模型出发，逐步建立 ChatGLM、智谱清言与大模型开放平台。它在中国大模型早期竞争中的独特位置，是把学术论文、开放权重、消费级对话和企业 API 连成一条路线。

## 一、家世与师承

GLM（General Language Model）由清华大学知识工程实验室等团队推动，智谱 AI 负责技术成果转化。GLM-130B 是中英双语预训练模型，ChatGLM 则把千亿级基座的能力压缩到更适合本地运行的对话模型，并与 CodeGeeX、CogView、CogVideo 等模型共同构成家族。

## 二、初次出世：ChatGLM

2023 年 3 月，ChatGLM-6B 开源并进入公众视野。它支持中英双语对话，可在相对有限的消费级 GPU 上运行，因此成为许多开发者接触中文大模型和本地部署的入口。

2023 年 6 月，ChatGLM2-6B 发布，改进上下文长度、推理能力和推理效率。8 月 31 日，智谱清言（ChatGLM）完成生成式人工智能服务备案并上线，研究模型开始转化为面向公众的产品。

## 三、成长与变法

- 从 GLM-130B 的预训练研究转向 ChatGLM 的轻量化开放模型；
- 通过指令微调、对齐和中文任务数据提高对话体验；
- 以 CodeGeeX、视觉和视频模型扩展多模态与代码能力；
- 通过智谱开放平台提供 API、微调、评测和模型即服务。

智谱的开放策略降低了中文开发者的门槛，但模型权重、许可证、训练数据和商业 API 仍需分别判断；“开源”并不等于所有技术细节和数据都完全透明。

## 四、2024 年：GLM-4 与 All Tools

2024 年，智谱把 GLM-4 家族推向更强的通用对话、代码、视觉和长上下文场景，并通过智谱清言与开放平台提供模型服务。All Tools 的路线把搜索、代码执行、绘图和其他外部能力纳入统一调用框架，使 GLM 从“会回答”走向“会使用工具完成任务”。

这一阶段的关键不是单一参数规模，而是把模型、工具、知识库、权限和工作流组合成可部署系统。智谱也因此从开源模型提供者进一步转向开发者平台和 Agent 基础设施提供者。

## 五、2025 年：推理模型与 Agent 平台

2025 年，智谱继续围绕 GLM 家族推进推理、全模态、代码和 Agent 平台化。其产品形态从单一聊天接口扩展到 API、企业知识库、工具调用和面向开发者的工作流编排。

## 六、2026 年：推理、全模态与企业 Agent

2026 年，智谱继续围绕 GLM 家族推进推理、全模态、代码和企业 Agent 平台。GLM 的历史主线从模型发布转向 API、知识库、工具调用、评测和行业部署的完整闭环。

## 七、年表与史家曰

| 时间 | 事件 |
|---|---|
| 2022 | GLM-130B 论文与模型进入开源研究生态 |

| 2023-06-25 | ChatGLM2-6B 发布 |
| 2023-08-31 | 智谱清言完成备案并上线 |
| 2024 | GLM-4、GLM-4V 与 All Tools 推进，开放平台和 Agent 能力扩展 |

| 2026 | 截至 8 月 15 日：全模态、推理模型与 Agent 平台继续演进 |

> **史家曰**：智谱以学术为根，以开放为桥，以清言入市。它证明中国大模型不只可以做应用，也可以从预训练架构、开源权重和开发者生态开始建立自己的技术血统。
